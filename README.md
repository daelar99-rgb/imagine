# 🎨 이매진 v3.78.0

봇이 답변을 마치면 메인 모델이나 보조 모델이 그 답변에서 그릴 장면을 고르고, NovelAI 이미지 API로 삽화나 만화를 그려 주는 RisuAI 플러그인입니다.
그린 그림은 봇의 추가 에셋(`nc_…`)으로 저장되고, 그 장면이 나오는 문단 바로 아래에 들어갑니다.
애드 에셋 모드에서는 봇 인물의 감정 표정 세트를 한꺼번에 그려 에셋으로 넣을 수 있습니다.

NovelAI 계정과 영구 API 토큰이 있어야 합니다.

## 설치

1. RisuAI 설정 → 플러그인 → ＋ 를 누르고 `이매진.js` 를 고릅니다.
2. 권한 확인 창이 뜨면 허용합니다 (API 3.0 플러그인). 권한은 세 가지입니다.
   - 요청 정리(replacer): 답변이 오면 자동으로 그리고, 모델에게 보내는 글에서 그림 태그를 지웁니다.
   - 본문 화면 접근: 답변 아래 버튼, 그림 위 버튼, 입력 칸 옆 버튼을 붙입니다.
   - 전체 DB 접근: 페르소나를 읽어 유저 인물의 생김새를 알아냅니다. 판을 올린 뒤 처음 그릴 때 뜨며, 답할 때까지 그리기가 멈춥니다.
3. 채팅 입력 칸의 ☰ 메뉴와 입력 칸 왼쪽에 「🎨 이매진」 버튼이 생깁니다. 누르면 이매진 창이 열립니다.
4. 창의 준비 탭에서 NovelAI 키를 넣습니다. 키는 NovelAI 웹 → 설정 → Account → Get Persistent API Token 에서 받는, `pst-` 로 시작하는 토큰입니다.

## 쓰는 법

이매진 창은 머리의 모드 토글([삽화] · [애드 에셋])로 작업을 고르고, 오른쪽 탭(등장인물 · 작가 · 설정)과 아래 탭(준비 · 삽화 목록 또는 에셋 목록)으로 화면을 바꿉니다. 창은 늘 준비 탭으로 열리고, × 를 눌러야 닫힙니다.

### 삽화 · 만화

1. [삽화] 모드의 준비 탭에서 여섯 단계를 차례로 고릅니다.
   1. LLM 모델 고르기: 장면을 고를 모델입니다. 메인 모델과 보조 모델 중에서 고릅니다 (기본은 보조).
   2. NovelAI 키 넣기
   3. NAI 모델 고르기: 목록에 없는 모델은 id 를 직접 넣습니다. 애드 에셋도 이 모델로 그립니다.
   4. 만화 또는 삽화: 만화(V5 이상)는 한 장에 2~4컷을 그리고 답변 속 대사를 말풍선으로 넣습니다. 삽화는 칸과 말풍선 없이 한 장면을 그립니다.
   5. 작가 고르기
   6. 장 수 고르기: 한 답변에 1~4장을 그립니다. 장마다 답변 속 다른 장면을 고르고, NAI 요청도 장마다 하나씩 보냅니다.
2. 봇이 답변을 마치면 자동으로 그립니다. 답변 아래 「🎨 이미지 생성」 버튼을 누르면 모델이 그 답변의 장면부터 다시 골라 그립니다 (이미 그림이 있어도 같습니다). 자동 그리기를 껐을 때는 이 버튼으로 그립니다. 버튼은 「씬 재구성 중」 → 「그리는 중」 단계와 게이지를 보여 주고, 그리는 동안 누르면 멈춥니다.
3. 그림 위에 마우스를 올리면(모바일은 그림을 누르면) 버튼 줄이 뜹니다. 그리는 동안에는 이 버튼에도 단계와 게이지가 나오고, 누르면 멈춥니다.
   - 🎨 이매진: 이매진 창을 엽니다.
   - 🔁 다시 그리기: 장면은 그대로 두고 그림만 새로 그립니다.
   - 🎬 씬 재구성: 모델이 장면부터 다시 고른 뒤 그립니다.
   - 🗑 지우기: 두 번 누르면 그림을 지웁니다.
4. 삽화 목록 탭에서 이 채팅에 들어간 그림을 답변별로 봅니다.
   - 「전체 · 그림 있음 · 그림 없음 · 지운 답변」으로 거를 수 있습니다. 「지운 답변」에는 답변이 지워진 뒤에도 남아 있는 그림이 모이며, 골라서 지웁니다.
   - 그림마다 ⋯ 메뉴에 🔁 다시 그리기, 🎬 씬 재구성, 📝 프롬프트 직접 고치기, 🗑 지우기가 있습니다.

### 애드 에셋

1. [애드 에셋] 모드의 준비 탭에서 아홉 단계를 차례로 고릅니다: LLM 모델 → 인물 고르기 → 복장 고르기 → 에셋 개수 → 감정 에셋 확인 → 작가 고르기 → NAI 모델 고르기 → 글로벌노트 → 애드 에셋.
2. 에셋 개수는 1 · 10 · 50 · 커스텀 중에서 고릅니다. 커스텀은 원하는 감정을 쉼표로 적으면 모델이 태그로 바꿔 그립니다. 감정 에셋 확인 단계에서는 특수 에셋을 직접 적어 넣을 수 있습니다.
3. NAI 모델 단계에서 레퍼런스를 켜면 인물과 복장 묶음마다 기준 그림을 먼저 그리고 멈춥니다. 마음에 들면 「✔ 이대로 나머지 N장 그리기」를 누릅니다.
4. 글로벌노트 단계에서는 봇이 새 에셋을 쓰도록 안내하는 글을 자동으로 써 줍니다. 직접 고칠 수도 있습니다.
5. 다 그린 그림은 봇의 추가 에셋(`c_인물_복장_감정`)으로 들어가고, 에셋 목록 탭에서 봅니다. 그림마다 「다시 그리기」와 「📝 프롬프트 고쳐 다시 그리기」가 있으며, 다시 그린 그림은 원래 자리에 들어갑니다.
6. 준비 탭의 「채팅에 에셋 그림 보이기」를 끄면 채팅에서 에셋 그림을 숨기고, 글로벌노트와 로어북의 에셋 칸도 뺍니다. 다시 켜면 되돌립니다.

### 등장인물

등장인물 탭에서 「📖 등장인물 분석」을 누르면 봇 설명, 로어북, 페르소나에서 인물을 읽어 생김새 표를 만듭니다.
인물마다 머리 모양 · 앞머리 · 머리색 · 눈 색 · 키 · 체형 · 상의 · 하의 · 신발의 아홉 칸이 있고, 그림을 그릴 때마다 이 표를 써서 같은 인물이 같은 모습으로 나오게 합니다. 칸은 직접 고칠 수 있습니다.

### 작가

- 내장 작가는 「이매진 그림체 (삽화용)」, 「프리셋1 (v5f)」, 「프리셋2 (v4.5f)」 세 가지입니다. 처음 설치하면 「이매진 그림체 (삽화용)」으로 그립니다.
- 내장 작가의 카드 그림은 바뀌지 않습니다. 직접 만든 작가는 그 작가로 마지막에 그린 그림이 카드에 나옵니다.
- 새 작가를 만들거나 내장 작가를 복제해서 고칩니다. 스텝, 샘플러, 가이던스, 리스케일은 작가마다 따로 저장됩니다.
- 「기본값으로」를 누르면 내장 작가를 처음 값으로 되돌립니다.

NAI API 키는 플러그인 설정의 `nai_api_key` 칸에도 들어갑니다. 이매진 창에서 넣은 키와 같은 값입니다.

## 다이나믹 프롬프트

작가가 「이매진 그림체 (삽화용)」일 때만 동작합니다.
모델이 장면마다 심각도를 1~10으로 매기고, 9 이상인 장면(보스의 마지막 일격, 생사가 걸린 위기, 심각한 부상)만 흑백 스케치로 그립니다.
강조색은 인물과 몬스터마다 다른 색을 씁니다. 무기를 든 인물은 무기가 지나간 궤적을, 마법은 효과를, 맨손 격투는 흔적을 그 색으로 그립니다. 피는 그리지 않습니다.

## 봇의 기존 그림 숨기기

설정 탭의 「이 봇의 그림」에서 켭니다. 이 봇의 백그라운드 임베딩, 정규식, Lua 트리거에서 에셋 그림을 띄우는 곳을 모델이 찾아 숨기고, 메시지와 첫 메시지에 바로 쓴 에셋 그림(`{{img::…}}` 등)도 화면에서 지웁니다.
이 봇에만 적용되고, 봇 정규식이 복잡하면 적용되지 않을 수 있습니다. 이매진은 봇 원문에 자기 표식만 넣으며, 끌 때는 그 표식만 걷어 냅니다.

## 알아 둘 점

- 리수는 플러그인 판을 올릴 때 NAI 키를 지웁니다. 새 판을 설치했다면 키를 다시 넣습니다. 리수 자체 이미지 설정에 넣은 키는 플러그인이 읽지 못합니다.
- 3.0.0부터 내부 이름이 `nai_comic` 에서 `imagine` 으로 바뀌었습니다. 2.x 판을 쓰고 있었다면 옛 플러그인을 지우고 새로 설치합니다. 설정과 작가는 그대로 이어집니다.
- 그림은 `{{image::nc_…}}` 태그로 답변에 들어가며, 모델에게 보내는 글에서는 이 태그를 지웁니다.
- 프롬프트는 영어 태그로 만들어 보냅니다. 모델이 인물 생김새를 지어내지 않도록, 캐스트 표에 없는 인물은 로어북을 다시 읽어 찾습니다.
- NAI 요청이 시간 초과(408)나 서버 오류(5xx)로 실패하면 3초 뒤에 두 번까지 다시 보냅니다.
- 우리마을, 리사이징처럼 본문 화면을 만지는 다른 플러그인과 함께 써도 그림 크기와 버튼이 깨지지 않도록 만들었습니다. 리사이징과 함께 쓸 때 봇 그림 숨기기는 두 플러그인이 각자의 표식으로 따로 합니다.
- 설정 탭 맨 아래 MADE BY 상자를 누르면 제작자 GitHub(https://github.com/daelar99-rgb)가 새 창으로 열립니다. 새 창이 막히면 주소를 복사합니다.
