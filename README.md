# 🎨 이매진 v3.102.2

봇 답변을 읽고 장면을 골라 NovelAI로 그린 뒤, 그 장면이 나온 문단 아래에 넣어 주는 RisuAI 플러그인입니다.
삽화·만화 외에, 봇이 두고 쓸 감정별 표정 그림을 한 번에 만드는 애드 에셋 기능도 있습니다.

## 설치

1. RisuAI 설정 → 플러그인 → ＋ 를 누르고 `imagine.js` 를 고릅니다. 파일은 [Releases](https://github.com/daelar99-rgb/imagine/releases/latest) 에서 받습니다.
2. 권한 확인 창이 뜨면 모두 허용합니다 (API 3.0 플러그인).
3. 리수 왼쪽 사이드바의 ☰ 를 펼치면 🌀 아래에 팔레트 그림과 「이매진」 글자가 있는 버튼이 생깁니다. 채팅 입력 칸 오른쪽의 ≡ 메뉴와 입력 칸 왼쪽에도 🎨 이매진 버튼이 생깁니다. 모바일 화면에는 사이드바가 없으니 ≡ 메뉴의 버튼을 씁니다. 입력 칸 왼쪽 버튼은 설정 탭에서 끌 수 있습니다.
4. 🎨 이매진 을 눌러 패널을 열고, 준비 탭에 NovelAI 영구 토큰(`pst-…`)을 넣습니다. 토큰은 NovelAI 웹 › 설정 › Account › Get Persistent API Token 에서 받습니다.

## 업데이트

깃허브에 새 버전이 올라오면 이매진을 열 때 머리줄의 애드 에셋 옆에 주황 점이 달린 **업데이트** 탭이 생깁니다. 탭을 누르면 새 버전의 업데이트 내역(건너뛴 버전이 있으면 그 내역까지)과, 리수에서 어디를 누르면 되는지를 그림으로 보여 줍니다. 버전마다 바뀐 점은 [CHANGELOG.md](https://github.com/daelar99-rgb/imagine/blob/main/CHANGELOG.md) 에도 있습니다.

1. 리수 왼쪽 위 ≡ → 톱니바퀴(설정) → 플러그인 을 엽니다.
2. 🎨 이매진 줄 오른쪽의 초록색 ＋ 를 누르고, 확인 창에서 YES 를 누릅니다.
3. 권한 확인 창이 다시 뜨면 모두 허용합니다. 그려 둔 그림, 이매진 설정, NovelAI 토큰은 그대로 남습니다.

업데이트 탭의 나중에 를 누르면 그 버전에는 탭을 다시 띄우지 않습니다. 초록색 ＋ 는 v3.81.0 이상을 설치한 뒤부터 뜹니다. v3.80.0 이하를 쓰고 있다면 [Releases](https://github.com/daelar99-rgb/imagine/releases/latest) 에서 `imagine.js` 를 받아 한 번 직접 설치해 주세요.
