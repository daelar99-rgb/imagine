# 🎨 이매진 v3.82.2

봇 답변을 NovelAI 그림으로 바꿔 주는 RisuAI 플러그인입니다. 메인 모델이나 보조 모델이 답변을 읽고 장면·대사·지금 입은 옷을 정하면, NovelAI 이미지 API로 그려 그 장면이 나온 문단 바로 아래에 넣습니다.
그림은 봇의 추가 에셋(`nc_…`)으로 저장되고, 채팅에는 `{{image::nc_…}}` 태그만 남습니다. 이 태그는 모델에게 보내는 요청에서 빠집니다.
답변마다 그리는 삽화·만화와 별도로, 봇이 두고 쓸 감정별 표정 그림을 한 번에 만드는 애드 에셋 기능도 있습니다.

## 설치

1. RisuAI 설정 → 플러그인 → ＋ 를 누르고 `이매진.js` 를 고릅니다.
2. 권한 확인 창이 뜨면 모두 허용합니다 (API 3.0 플러그인). 창은 따로따로 뜹니다.
   - replacer: 답변이 오면 자동으로 그리고, 요청에서 그림 태그를 빼는 데 씁니다.
   - 본문 화면 접근: 답변 아래 버튼, 그림 위 버튼, 입력 칸 옆 버튼을 그리는 데 씁니다.
   - 전체 DB 접근: 페르소나를 읽는 데 씁니다. 업데이트 뒤 처음 그릴 때 뜨며, 답할 때까지 그리기가 멈춰 있습니다.
3. 채팅 입력 칸 오른쪽의 ≡ 메뉴와 입력 칸 왼쪽에 🎨 이매진 버튼이 생깁니다. 누르면 패널이 열립니다.
4. 패널의 준비 탭에서 NovelAI 키(`pst-` 로 시작하는 영구 토큰)를 넣습니다. 키는 NovelAI 웹 › 설정 › Account › Get Persistent API Token 에서 받습니다.

### 업데이트

v3.82.0 부터는 새 버전이 나오면 두 곳에서 알려 줍니다.

- 이매진 패널 머리의 「애드 에셋」 옆에 주황색 점이 붙은 「업데이트」 탭이 생깁니다. 누르면 리수 화면을 본뜬 그림 다섯 장으로 어디를 누를지 보여 줍니다(≡ → 톱니바퀴 → 플러그인 → 이매진 줄의 초록색 + → YES). 「다음에」를 누르면 그 버전은 다시 알리지 않고 탭도 사라집니다.
- 리수 설정 → 플러그인에서 이매진 옆에 초록색 + 가 생깁니다. 누르고 확인하면 리수가 깃허브에서 새 버전을 받아 바로 바꿔 끼웁니다.

설치하면 리수가 NAI 키를 지우고 권한을 다시 묻습니다. 키를 다시 넣고, 권한 창은 모두 허용해 주세요. v3.80.0 이하를 쓰고 있다면 v3.82.2 는 한 번 직접 받아 설치해야 합니다.

## 쓰는 법

패널 머리에서 [삽화] 와 [애드 에셋] 중 하나를 고릅니다. 패널은 늘 준비 탭으로 열리고, × 를 눌러야 닫힙니다.

### 삽화 · 만화

1. 준비 탭의 여섯 단계를 차례로 고릅니다.
   - ① LLM 모델 고르기: 장면을 정할 모델입니다 (메인 · 보조, 기본 보조).
   - ② NovelAI 키 넣기
   - ③ NAI 모델 고르기: 기본 `nai-diffusion-4-5-full`. 목록에 없는 모델은 id 를 직접 넣습니다.
   - ④ 만화 / 삽화: 만화(V5 이상)는 한 장에 2~4컷을 그리고 답변 속 대사를 그대로 말풍선에 넣습니다. 대사는 컷마다 하나이며, 말한 인물의 태그 끝에 붙습니다. 삽화는 칸과 말풍선 없이 한 장면을 그립니다.
   - ⑤ 작가 고르기
   - ⑥ 장 수 고르기: 1~4장. 장마다 답변 속 다른 장면을 고르고, NAI 요청도 장마다 하나씩 갑니다.
2. 이제 답변이 오면 자동으로 그립니다. 답변 아래 「🎨 이미지 생성」 버튼으로 직접 그릴 수도 있습니다. 버튼은 그리는 동안 「씬 재구성 중」 → 「그리는 중」 단계와 게이지를 보여 주고, 누르면 멈춥니다.
3. 그림 위에 마우스를 올리거나 그림을 누르면 버튼 줄이 뜹니다.
   - 🎨 이매진: 패널을 엽니다.
   - 🔁 다시 그리기: 장면은 그대로 두고 그림만 새로 그립니다.
   - 🎬 씬 재구성: 모델이 장면부터 다시 고릅니다.
   - 🗑 지우기: 두 번 눌러야 지워집니다.
   - 🔁 · 🎬 버튼도 그리는 동안 단계와 게이지를 보여 주고, 다시 누르면 멈춥니다.
4. 삽화 목록 탭에서 이 채팅의 그림을 답변별로 봅니다. 「전체 · 그림 있음 · 그림 없음 · 지운 답변」 으로 거르고, 그림마다 ⋯ 메뉴에서 다시 그리기와 📝 프롬프트 직접 고치기를 씁니다. 「지운 답변」 은 답변을 지워 주인이 없어진 그림을 골라 지우는 곳입니다.

### 애드 에셋

봇이 두고 쓸 감정별 표정 그림을 만들어 봇 에셋에 넣습니다. 준비 탭에서 다음을 차례로 고릅니다.

1. LLM 모델 고르기 (삽화와 따로 고릅니다)
2. 인물 고르기
3. 복장 고르기
4. 에셋 개수: 1 / 10 / 50 / 커스텀. 커스텀은 쉼표로 감정을 적습니다.
5. 감정 에셋 확인: 특수 에셋(요리 등)을 직접 적을 수 있습니다.
6. 작가 고르기 (삽화와 따로 고릅니다)
7. NAI 모델 고르기: 레퍼런스를 켜면 기준 그림을 먼저 그려 보여 주고, 「이대로 나머지 그리기」 를 눌러야 나머지를 그립니다.
8. 글로벌노트: 봇이 에셋을 쓰는 법을 자동으로 적습니다. 직접 고칠 수도 있습니다.
9. 애드 에셋: 그리기 시작합니다.

에셋 목록 탭에서는 만든 그림을 보고, 마음에 들지 않는 그림을 다시 그리거나 📝 프롬프트를 고쳐 다시 그립니다. 다시 그린 그림은 원래 자리에 들어갑니다.

### 등장인물 · 작가

- 등장인물 탭의 📖 등장인물 분석은 봇 설명, 로어북, 페르소나를 읽고 인물마다 아홉 칸(머리 모양 · 앞머리 · 머리색 · 눈 색 · 키 · 체형 · 상의 · 하의 · 신발)을 채웁니다. 그림마다 이 표를 써서 같은 인물이 같은 모습으로 나옵니다. 칸은 직접 고칠 수 있습니다.
- 작가 탭에는 내장 작가 셋이 이 차례로 있습니다: 이매진 그림체 (삽화용), 프리셋1 (v5f), 프리셋2 (v4.5f). 처음 쓰는 사람은 이매진 그림체로 시작합니다.
- 내장 작가의 카드 그림은 고정입니다. 다른 작가의 카드에는 그 작가로 마지막에 그린 그림이 보입니다.
- 작가를 새로 만들거나 복제해서 고칩니다. 스텝, 샘플러, 가이던스, 리스케일은 작가마다 따로 둡니다. 내장 작가를 고쳤다면 「기본값으로」 로 되돌립니다.

| NAI 모델 | `nai-diffusion-4-5-full` | 준비 탭 ③ 과 같은 값입니다 |
| 답변이 오면 자동으로 그리기 | 켬 | 끄면 버튼으로만 그립니다 |

| 유저 인풋 우선 | 끔 | 켜면 유저 입력이 부른 상황을 먼저 그립니다. 끄더라도 유저 입력은 참고용으로 늘 보냅니다 |

| PC 가로 | 480px | 채팅 속 그림의 가로 크기 |

| 인물 칸을 채팅 변수로 쓰기 | 켬 | 인물마다 지금의 아홉 칸과 그 밖의 특징, 장소를 채팅 변수에 적습니다 |

플러그인 설정 화면의 `nai_api_key` 칸이 패널의 NAI API 키와 같은 값입니다.

## 다이나믹 프롬프트

「이매진 그림체 (삽화용)」 작가로 그릴 때만 동작합니다. 모델이 장면마다 심각도(1~10)를 매기고, 기준 이상인 장면만 흑백 스케치로 그립니다. 기준은 설정 › 그리기의 「심각도 기준」에서 바꾸며, 기본값 9는 보스와의 마지막 일격, 생사가 걸린 위기, 심각한 피해 같은 장면입니다. 이때 검기·마법 효과·타격 흔적에만 색을 넣고, 색은 인물마다 다르게 정합니다. 그 밖의 장면은 평소처럼 컬러로 그립니다.

## 이 봇의 그림 숨기기

배경 임베딩, 정규식, Lua 로 에셋 그림을 띄우는 봇에서 이매진 그림과 봇 그림이 겹칠 때 씁니다. 모델이 봇 원문에서 그림을 띄우는 자리를 찾아 숨기고, 메시지에 직접 쓴 그림도 숨깁니다. 봇마다 따로 켜며, 봇 정규식이 복잡하면 적용되지 않을 수 있습니다. 끄면 이매진이 넣은 표식만 걷어 내고 원문은 그대로 돌아옵니다.

## 알아 둘 점

- **판을 올리면 NAI 키가 지워집니다.** RisuAI가 플러그인을 다시 설치하면서 인자를 비우기 때문입니다. 업데이트 뒤에는 준비 탭에서 키를 다시 넣습니다.
- RisuAI 자체 이미지 설정에 넣은 NovelAI 키는 플러그인이 읽을 수 없습니다. 키는 이매진에 따로 넣습니다.
- v3.0.0 부터 내부 이름이 `nai_comic` 에서 `imagine` 으로 바뀌었습니다. 옛 플러그인을 지우고 새로 설치합니다. 설정과 작가는 그대로 이어집니다.
- 그림 한 장마다 NovelAI Anlas 가 듭니다. 장 수와 애드 에셋 개수를 정할 때 참고합니다.
- NovelAI 가 잠시 응답하지 않으면(408 · 5xx) 3초 뒤 두 번까지 다시 보냅니다.
- 프롬프트는 영어로 만듭니다. 만화의 말풍선 대사만 답변 원문 그대로 넣습니다.
- 그림 위 버튼과 그림 크기는 다른 플러그인 CSS 에 흔들리지 않도록 인라인으로 고정했습니다. 우리마을·리사이징과 함께 켜도 됩니다.
- 설정 탭 맨 아래 MADE BY 상자의 「깃허브 열기 ↗」 를 누르면 만든 사람의 GitHub 이 열립니다. 새 창이 막히면 상자에 보이는 주소를 길게 눌러 복사합니다.
